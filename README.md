# Nothing Music Widget - Android Native
Widget nativo para Nothing OS y Android con 3 capas de visualización, ecualizador dot-matrix y control de música en tiempo real.

## Compilación automática en GitHub
Este repositorio cuenta con un flujo de GitHub Actions (`.github/workflows/build_apk.yml`) que compila automáticamente el archivo `app-debug.apk` listo para instalar en cualquier teléfono Android.
